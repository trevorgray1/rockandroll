# Rock & Roll Genealogy Project

## Project Status: On Hold (as of March 3, 2026)

This project is currently paused. See below for next steps and current status.

### Next Steps (when resuming)
- Expand artist data sources (connect to Discogs/MusicBrainz)
- Implement detailed artist profiles and genealogy views
- Add search/filter functionality in frontend
- Connect frontend to backend API for dynamic data
- Add user experience features (auth, favorites, visualizations)
- Update documentation and add tests

Feel free to reach out if you wish to resume or contribute.

This project is an encyclopedia and genealogy explorer for rock & roll musicians, bands, and their influences. It uses AWS for hosting, serverless backend, and graph database for relationships.

## Structure
- `frontend/`: Static site (React/Next.js)
- `backend/`: API code (Node.js, Python, or Lambda)
- `infra/`: Terraform scripts and modules for AWS resources
- `data/`: Data ingestion scripts and sample datasets
- `docs/`: Documentation and architecture notes
